Mã TC Tên kịch bản Các bước thực hiện Kết quả mong đợi Mức độ

2. Chọn tài khoản Google hợp lệ		 Đăng nhập thành công, nhận Firebase JWT, profile được đồng bộ vào bảng users, điều hướng vào danh sách tài liệu. Critical

2. Xác nhận đăng xuất		 Phiên làm việc kết thúc, hủy token trong bộ nhớ, xóa trạng thái ViewModel, quay về màn hình Login. High
TC-AUTH-04 Đăng ký Token FCM 1. Đăng nhập vào app trên thiết bị
2. Kiểm tra token gửi về backend		 Token FCM được lưu trữ thành công vào trường fcm_token của người dùng trong Supabase. Medium

🔒 4. Phân hệ Bảo Mật & Storage (Security & RLS)

Mã TC Tên kịch bản Các bước thực hiện Kết quả mong đợi Mức độ
TC-SEC-01 Chặn xem tài liệu Private (RLS) Tài liệu đặt is_public: false. Người lạ query SELECT Supabase RLS trả về 0 bản ghi, metadata được bảo vệ tuyệt đối. Critical
TC-SEC-02 Chặn chỉnh sửa trái phép User B cố gắng UPDATE tài liệu của User A RLS Policy documents_update từ chối thao tác, báo lỗi không đủ quyền hạn. Critical
TC-SEC-03 Xem file qua Signed URL User có quyền view mở file đính kèm Hệ thống sinh Signed URL có chữ ký bảo mật, hết hạn sau 300 giây. Critical
TC-SEC-04 Chặn tải file trực tiếp (Public URL) Thử tải file qua URL công khai thông thường Storage trả về HTTP 403 / 404 do Bucket documents được đặt là Private. Critical
