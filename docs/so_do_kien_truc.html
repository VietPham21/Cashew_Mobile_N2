📱 1. Client Tier (Flutter App)

Presentation Layer UI & State

Screens: DocumentsListPage, DocumentDetailPage, DocumentFormPage, BorrowRequestsPage, LoginPage, LocationPickerPage.

State: Provider + ChangeNotifier ViewModels (AuthViewModel, DocumentsViewModel, BorrowViewModel)
▼ Gọi UseCase & Đọc Entity

Domain Layer Core Logic

Use Cases: SignInWithGoogle, SignOut, Thao tác CRUD tài liệu.

Entities: StudyDocument, BorrowRequest, Permission, UserEntity.

Contracts: DocumentsRepository, BorrowRepository (Interface).

▼ Triển khai Interface

Data Layer Data Access

Repositories Impl: DocumentsRepositoryImpl, BorrowRepositoryImpl, AuthRepositoryImpl.

Mappers: toMap, fromMap, DocumentType parser.

🔥 2. Identity & Messaging (Firebase)

Firebase Authentication

• Đăng nhập Google (OAuth 2.0).

• Quản lý phiên đăng nhập.

• Cấp JWT ID Token gửi sang Supabase để định danh.

Firebase Cloud Messaging (FCM)

• Đăng ký FCM Device Token.

• Gửi thông báo đẩy khi có người mượn tài liệu hoặc được duyệt quyền.

• Lắng nghe thông báo Foreground/Background.

Luồng xác thực: Flutter lấy ID Token từ Firebase Auth ➔ truyền vào Supabase Client header ➔ RLS tự động xác minh qua email / UID.
⚡ 3. Database & Storage (Supabase)

PostgreSQL Database (RLS Protected)

  • documents: Metadata, tags, GPS coordinates.
  • permissions: Quyền view / edit theo user.
  • borrow_requests: Yêu cầu mượn (pending/approved).
  • users: Profile & FCM device token.
  • notifications: Lịch sử thông báo in-app.

Row Level Security (RLS)

Kiểm soát bảo mật trực tiếp ở database bằng SQL Policies và hàm current_app_user_id().

Private Storage Bucket

Bucket documents được đặt ở chế độ riêng tư (Private). Client truy cập tệp qua Signed URLs có thời hạn 300 giây.
